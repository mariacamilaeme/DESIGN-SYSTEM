Iconos

Retícula de 24 px, trazo de 1,5 px con extremos redondeados y relleno al 12 % en las formas cerradas. Toman el color del texto. Pasa el cursor: los que tienen sentido se mueven una vez.

Tamaño

Ningún icono coincide con

Prueba con otra palabra: los nombres y las etiquetas están en español.

Glifos de estado

Formas de 10 px que distinguen un estado sin depender del color. Van dentro de las píldoras, delante de la etiqueta.

Indicadores

El giro de carga y el pulso son los únicos movimientos en bucle del sistema. El éxito y el error se dibujan una vez al aparecer.

cargando

Arco que gira mientras una operación está en marcha. Con movimiento reducido gira más despacio.

En tránsito

en-curso

Pulso suave para lo que ocurre ahora: viajes en curso, sincronización activa.

exito-animado

Se dibuja al insertarse.

error-animado

Círculo y cruz, una sola vez.

progreso

Lee la variable --progreso, de 0 a 100.

64 %

Ilustraciones de estado vacío

Un dibujo mínimo que se traza una vez, una línea de texto y una acción. Usan las variables del tema, así que se incrustan en línea.

Uso

Todos los formatos salen de una sola fuente: iconos/fuente/iconos.mjs. El detalle está en iconos/LEEME.md.

HTML

<link rel="stylesheet" href="iconos/iconos.css">
<script src="iconos/iconos.js"></script>

<button>
  <span data-icono="descargar"></span>
  Descargar
</button>

JavaScript

el.innerHTML = Obsidiana.icono('filtro', {
  tamano: 20,
  titulo: 'Filtrar',
});

React

import { IconoDescargar } from './iconos/react';

<IconoDescargar tamano={16} />
